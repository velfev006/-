# Предметная область

## 1. Описание предметной области

Здоровье и физическая форма человека во многом определяются энергетическим балансом: соотношением калорий, полученных с пищей, и калорий, потраченных организмом за сутки. Если поступление энергии систематически превышает расход, масса тела растёт, если ниже, масса снижается. Для контроля этого процесса необходимо учитывать параметры пользователя (пол, возраст, рост, вес, уровень активности), данные о приёмах пищи и данные о тренировках. Каждая запись характеризуется датой, названием и количеством калорий.

Человек получает энергию от продуктов питания (завтрак, обед, ужин, перекусы), а расходует её на поддержание жизнедеятельности (основной обмен), повседневную активность и физические тренировки (бег, силовые занятия, плавание и др.). В рамках программной реализации выполняется:

* хранение данных о приёмах пищи и тренировках;
* учёт даты каждой записи;
* расчёт суточной нормы калорий пользователя;
* расчёт ежедневного энергетического баланса и его накопленного значения;
* определение показателей, характеризующих отклонение от поставленной цели (набор массы, похудение, поддержание формы).

## 2. Динамика энергетического баланса

Основной обмен (по формуле Миффлина — Сан Жеора):

BMR = 10·m + 6,25·h − 5·a + s

где:

* m — масса тела, кг;
* h — рост, см;
* a — возраст, лет;
* s — константа (+5 для мужчин, −161 для женщин).

Суточный расход энергии:

E(t) = BMR · K + W(t)

Энергетический баланс за день:

D(t) = C(t) − E(t)

Накопленный баланс:

S(t) = S(t−1) + D(t)

где:

* K — коэффициент физической активности (1,2 – 1,9);
* W(t) — калории, потраченные на тренировках за день t;
* C(t) — калории, полученные с пищей за день t;
* D(t) — баланс за день t;
* S(t) — накопленный баланс на конец дня t.

Если D(t) > 0, фиксируется профицит калорий, если D(t) < 0 — дефицит. Ожидаемое изменение массы тела оценивается приближённо: ΔM ≈ S(t) / 7700 кг.

Если суточное потребление выходит за допустимые границы цели (например, |D(t)| превышает заданный порог), система формирует предупреждение пользователю.

## 3. Классы предметной области

1. **Record (базовая запись)** — абстрактный класс для всех записей трекера. Хранит поля `date` (дата) и `calories` (количество калорий).
2. **Meal (приём пищи)** — запись, увеличивающая поступление энергии (завтрак, обед, ужин, перекус). Наследует `date` и `calories` от `Record`, дополнительно хранит название блюда и массу порции, а также белки, жиры и углеводы.
3. **Workout (тренировка)** — запись, увеличивающая расход энергии (бег, силовая, плавание). Наследует `date` и `calories` от `Record`, дополнительно хранит тип тренировки и длительность.
4. **User (пользователь)** — хранит параметры пользователя (пол, возраст, рост, вес, коэффициент активности, цель), а также список всех записей. Выполняет расчёт основного обмена и суточной нормы калорий.
5. **Tracker (трекер)** — управляющий класс. Рассчитывает энергетический баланс по дням, накопленный баланс, формирует отчёты за период и предупреждения об отклонении от цели.
